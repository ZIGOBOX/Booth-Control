GITHUB - BOOTH CONTROL

Le dépôt GitHub doit contenir :
1) BoothControlProject.zip à la racine
2) .github/workflows/build-apk.yml

Ensuite :
- Onglet Actions
- Build Booth Control APK
- Run workflow (ou laisser le push le lancer)
- Une fois vert : ouvrir le run
- Artifacts > Booth-Control-APK
- Télécharger puis extraire : Booth-Control.apk

NE PAS extraire BoothControlProject.zip dans GitHub : le workflow le fait automatiquement.
